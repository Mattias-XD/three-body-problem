The commented-out `MANUAL_IC` block lets you enter the first body's initial position (`x`, `y`) and the reference period (`T`); the other two bodies start at `(-0.5, 0)` and `(0.5, 0)`, and all initial velocities are zero.

This project builds on the article **Three-body periodic collisionless equal-mass free-fall orbits revisited** by Ivan Hristov, Radoslava Hristova, Veljko Dmitrašinović and Kiyotaka Tanikawa, published in *Celestial Mechanics and Dynamical Astronomy* 136, 7 (2024).

- [Published article](https://doi.org/10.1007/s10569-023-10177-w)
- [Open-access preprint](https://arxiv.org/abs/2308.16159)
- [Authors' initial-condition library and supplementary material](https://db2.fmi.uni-sofia.bg/3bodyfree/)
- [Original 80-digit catalogue: sol_80.txt](https://db2.fmi.uni-sofia.bg/3bodyfree/sol_80.txt)

The normalizing flow in this project has been trained on initial conditions from the authors' library. The catalogue contains 24,582 initial-condition entries, with columns `x`, `y`, `T` and `T*`. Credit for the original catalogue and periodic-orbit search belongs to the article's authors.

## Verification results

The [original initial-condition verification folder](verification/original_initial_conditions/) contains the result plots for **31 randomly selected, previously reported periodic initial conditions** from `sol_80.txt`. These are catalogue initial conditions, rather than new candidates generated by the normalizing flow.

The PNG files are uploaded unchanged, at their original resolution. Open an image and use GitHub's download button to obtain the original file. Filenames retain the catalogue identifier and run timestamp. [SHA256SUMS.csv](verification/original_initial_conditions/SHA256SUMS.csv) records the original image checksums.

These plots were produced by the project's verification runs; the two simplified scripts below are provided to make the numerical method easier to inspect. Numerical return errors and classifications depend on the chosen precision, tolerances and integration duration.

## Code

Both scripts are in the [code folder](code/).

### RK4 base

[rk4_mpmath_base.py](code/rk4_mpmath_base.py) is the most stripped-down version of the project's integrator, intended to make the method easy to inspect and verify. In general, it:

1. Loads a selected initial condition and its reference period from the published catalogue.
2. Lets you adjust the hyperparameters, including the catalogue row, number of periods, working precision, tolerances and plotting sample interval.
3. Builds the initial state vector from the three bodies' positions and velocities, and defines Newton's equations of motion with three unit masses and `G = 1`.
4. Defines a classical fourth-order Runge–Kutta step and adaptive step-size control by comparing one full step with two half steps.
5. Integrates the equations of motion with adaptive RK4, printing accepted steps, rejected steps and progress in the terminal.
6. Calculates the final shape, position, velocity and full-state return errors, compares them with the periodicity threshold, and displays the orbit plot.

The return errors measure how closely the final configuration matches the initial configuration. They are distinct from the local error estimate used to control step size. A threshold-based classification is a numerical check, rather than a mathematical proof of periodicity.

Plot samples are retained in memory. The script does not write result files or checkpoints.

### RK4 base V1.5

[rk4_mpmath_base_V1.5.py](code/rk4_mpmath_base_V1.5.py) adds interactive animation of the trajectories and an alternative view of the triangle formed by the three bodies, with a different colour for each side. Controls adjust playback speed, camera tilt and trail length. It also includes a commented-out manual input block for `x`, `y` and `T`.

Use the tilt slider to change the viewing angle. You can also rotate the 3D view with the mouse in an interactive Matplotlib window; the mouse button depends on the Matplotlib version and backend. Right-drag commonly zooms rather than tilts.

### Running the scripts

Install Python 3 and the dependencies:

```bash
python3 -m pip install mpmath numpy matplotlib
```

Download [sol_80.txt](https://db2.fmi.uni-sofia.bg/3bodyfree/sol_80.txt) from the authors' website and save it at `code/Listor/sol_80.txt`. This location preserves the scripts' existing catalogue path:

```text
code/
├── Listor/
│   └── sol_80.txt
├── rk4_mpmath_base.py
└── rk4_mpmath_base_V1.5.py
```

Edit the clearly marked `HYPERPARAMETERS` block near the top of the chosen script, then run one of:

```bash
python3 code/rk4_mpmath_base.py
python3 code/rk4_mpmath_base_V1.5.py
```

Use a local graphical Python environment with an interactive Matplotlib backend to display and manipulate the plots. The default high-precision settings can require substantial computation time. The integration stops at the requested end time or the configured accepted-step limit.
